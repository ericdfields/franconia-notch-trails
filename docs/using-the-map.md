# Using the map

- Drag to pan.
- Scroll or use `+` / `−` to zoom.
- Right-drag, `Q`, or `E` to rotate.
- Press `H` to return home.
- Press `U` to hide/show the interface for screenshots.
- Press `/` to search trails.

Trail cards show distance, gain/loss, elevation range, data source, wilderness status, and known access. Bike access is shown only where the source data supports it; otherwise Franconia Notch routes are treated as hiking-only.

Deep links use `#trail=Trail%20Name`.
