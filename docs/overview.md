# Overview

Franconia Notch Trails is a map for getting a feel for the hiking routes around Cannon Mountain, Franconia Ridge, the Kinsmans, and the Notch corridor. It is not turn-by-turn navigation.

The map shows:

- **Franconia Notch State Park** as the painted region outline.
- **Trails** from OpenStreetMap and USFS inventory, grouped into clickable named routes.
- **Water and landmarks** including Echo Lake, Profile Lake, the Basin, the Pemigewasset River, peaks, towns, and context roads.
- **Terrain** from AWS Terrain Tiles, exaggerated into an isometric watercolor diorama.

Bike access is intentionally conservative: this is a hiking-first area, so trails are considered foot-only unless source data explicitly says bicycles are allowed.
